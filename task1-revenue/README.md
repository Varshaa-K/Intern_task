# Revenue Analysis using Python

# Task 1 Overview
This project analyzes revenue data using Python. It calculates the total revenue, maps revenue IDs to their corresponding names, and visualizes the revenue values using a Matplotlib bar chart.

# Features
- Calculate total revenue from keys starting with `Rev`.
- Map revenue IDs to human-readable names.
- Display `Unknown` for IDs not found in the revenue types.
- Visualize revenue values using a bar chart.
- Format all displayed numeric values to three decimal places.

# Technologies Used
- Python
- Matplotlib

# Installation

Install Matplotlib:

pip install matplotlib

# How to Run

python revenue.py
